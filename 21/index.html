Because these rate limits apply organization-wide, concurrent executions across multiple teams exhausted the strict one-request-per-second quota and caused severe throttling via exponential backoff. To resolve this, Booking.com contributed a fix upstream to the Terraform AWS provider to make those extra API calls optional when only the organization ID is needed. This optimization eliminated nearly one million unnecessary weekly requests, recovered hundreds of pipeline-hours, and restored predictable pipeline execution speeds.
