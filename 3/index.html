How we improved APM Java startup by encoding a prefix trie as a JVM constant ↗

Datadog's Java APM agent must quickly evaluate tens of thousands of class names during JVM startup to filter out uninteresting classes before executing detailed instrumentation checks. To minimize cold-start overhead during the JIT-unoptimized premain phase, the team created ClassNameTrie, which encodes a prefix trie directly into a single JVM string constant loaded via an ldc bytecode instruction. The compact encoding packs control metadata, branch characters, inline segments, and jump offsets into 16-bit char elements, eliminating resource I/O and object creation costs. This approach outperformed classic radix tries and yielded up to a 5x speedup over legacy code-based matchers on Java 8 while contributing to an overall 24% reduction in instrumented application startup overhead.
