How we could save petabytes of cache storage with Zstandard and Pingora ↗

To address rising hardware and memory costs across its global CDN infrastructure, Cloudflare prototyped Cache Transcoding to expand effective cache capacity using Zstandard (zstd) within its Pingora proxy. The system selectively compresses eligible uncompressed text responses over 4 KiB using zstd level 3 upon cache fill, storing the compressed payload on disk and transferring it across Tiered Cache nodes before decoding it only on the final client-facing hop. In controlled testing, eligible assets shrank to roughly one-third of their original size (a 2.8x compression ratio) with an encoding cost of 4.31 ns/byte and a decoding cost of 1.56 ns/byte. This single-time compression trade-off expands effective cache capacity by petabytes, improves object retention density, and reduces cross-data center bandwidth usage with only a minor CPU overhead.
