Critical remote code execution in vm2, a widely used Node.js sandbox library ↗

GitLab's Threat Research Group identified a critical sandbox escape vulnerability (CVSS 10.0) in vm2, a widely used Node.js sandboxing library. The flaw allows untrusted code to break isolation by exploiting default configurations copied directly from the library's quick start documentation, specifically when require.external is enabled alongside a broad require.root. Because the resolver defaults context to host, requiring vm2 itself loads the unwrapped module via Node's native require(), enabling the attacker to spawn an unrestricted inner sandbox with access to child_process. While vm2 version 3.11.7 blocks this specific exploit chain, fully mitigating the underlying risk requires manually restricting require.root and changing the context setting, though process or container isolation is recommended for running untrusted code.
