How we built an async-aware Python profiler ↗

Traditional Python profilers flatten asyncio execution stacks into independent task traces, obscuring parent-child relationships and making async performance regressions hard to diagnose. To restore execution context, Datadog built an async-aware profiling model that tracks task dependencies to reconstruct nested task relationships into accurate stacked flame graphs. To eliminate the high overhead of making per-task process_vm_readv system calls during sampling, they switched to an in-process memcpy guarded by a POSIX signal handler that safely intercepts memory faults. This architecture reduced the profiler's CPU overhead by over 60%, enabled higher-fidelity profiling in production, and uncovered significant CPU bottlenecks across Datadog's Python services.

Building a post-quantum certificate authority with Merkle Tree Certificates ↗

To prevent the performance degradation and scaling issues caused by large post-quantum cryptographic signatures in Web PKI, Cloudflare is launching a certificate authority that supports Merkle Tree Certificates (MTCs). MTCs batch certificates into an append-only Merkle tree, allowing clients to verify certificates using compact inclusion proofs against a signed tree head instead of validating individual, heavy signatures. This "issue by logging" architecture integrates certificate transparency directly into the issuance process rather than treating it as an add-on. A recent large-scale experiment with Google Chrome demonstrated that using landmark-relative MTCs, which distribute tree metadata out-of-band, resulted in a 9% faster median handshake compared to classical signature chains.

Preventing quantum downgrade attacks against IPsec ↗

Cloudflare, in collaboration with the IETF, has developed and implemented a mitigation against quantum downgrade attacks for the IPsec protocol. The vulnerability stems from a design flaw in IKEv2 where endpoints only sign outbound messages rather than the entire handshake transcript, allowing an on-path quantum attacker to force a fallback to classical cryptography. To resolve this, the new IKE_SA_INIT_FULL_TRANSCRIPT_AUTH extension introduces full transcript authentication, requiring both parties to sign the complete handshake history. This extension uses an unconditional notification trick to prevent attackers from stripping the protection, and Cloudflare has made it available in beta for its WAN and Magic Transit products.

The making of the Yelp Assistant UI ↗

To overcome the slow deployment cycles of mobile app stores while building the LLM-powered Yelp Assistant, Yelp implemented a hybrid user interface combining native components with a server-driven UI (SDUI) framework called CHAOS. The architecture separates the static view template, which is fetched once at the start of a session, from the dynamic conversation data that hydrates the UI as the chat progresses. By utilizing a reactive, turn-based chat loop, the client handles optimistic updates for user messages and typing indicators locally while relying on backend-driven "client actions" to manage state changes like disabling input when a chat ends. This hybrid approach allowed Yelp to maintain multi-platform consistency across iOS and Android while enabling rapid, server-side updates to the conversational experience without requiring app store releases.
