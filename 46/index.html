Adding Async Streaming to Postgres Foreign Data Wrappers ↗

Traditional Postgres Foreign Data Wrappers suffer from high memory pressure and blocked execution because they rely on synchronous, pull-based batch fetching. Supabase solves this by introducing asynchronous streaming to their Rust-based Wrappers framework, decoupling remote network I/O from the Postgres execution engine. A background async task fetches remote rows incrementally and passes them to Postgres through a bounded, size-limited memory channel. This hybrid architecture drastically reduces memory usage during billion-row scans and accelerates the time-to-first-result for analytical queries against systems like ClickHouse.

Corrosion ↗

Fly.io built Corrosion, an unconventional open-source service discovery and state synchronization system, to route global network requests without relying on traditional distributed consensus protocols like Raft. Inspired by link-state routing protocols such as OSPF, Corrosion uses a SWIM-based gossip protocol and cr-sqlite to propagate SQLite database changes across a global WireGuard mesh without central coordination. Abandoning distributed consensus eliminated geographic latency bottlenecks, but introduced severe production incidents stemming from Rust concurrency deadlocks, expensive DDL migrations, and runaway event loops. To harden the architecture, the team implemented event-loop watchdogs, deterministic simulation testing via Antithesis, and regionalized the global state into a two-level database scheme to reduce blast radius.
