Corrosion ↗

Fly.io built Corrosion, an unconventional open-source service discovery and state synchronization system, to route global network requests without relying on traditional distributed consensus protocols like Raft. Inspired by link-state routing protocols such as OSPF, Corrosion uses a SWIM-based gossip protocol and cr-sqlite to propagate SQLite database changes across a global WireGuard mesh without central coordination. Abandoning distributed consensus eliminated geographic latency bottlenecks, but introduced severe production incidents stemming from Rust concurrency deadlocks, expensive DDL migrations, and runaway event loops. To harden the architecture, the team implemented event-loop watchdogs, deterministic simulation testing via Antithesis, and regionalized the global state into a two-level database scheme to reduce blast radius.

What are MCP Servers? ↗

The Model Context Protocol (MCP) standardizes how AI applications and LLMs connect to external data sources and tools, functioning similarly to an API with built-in introspection. Unlike stateless request-response architectures or serverless functions, MCP servers maintain long-lived lifecycles and support multiplexing and server push. Running these servers securely often requires isolating them on remote infrastructure rather than exposing local secrets directly on the client machine. Ultimately, MCP shifts the paradigm from embedding LLMs into existing software to equipping AI models with custom tools and domain-specific workflows.

JIT WireGuard ↗

Fly.io faced scalability and reliability issues caused by maintaining hundreds of thousands of stale WireGuard peer configurations in the Linux kernel across their global gateway servers. To solve this, they implemented a just-in-time (JIT) provisioning system that pulls peer configurations from their API only when an incoming connection attempt is detected. By using BPF filters to intercept handshake packets and performing a partial Noise protocol handshake, the system identifies the peer and dynamically installs the configuration into the kernel on demand. This approach significantly reduced memory overhead on gateway servers, eliminated kernel performance degradation, and improved overall system stability.
