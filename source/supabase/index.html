Realtime or Pipelines? How to choose the right tool ↗

Supabase examines the architectural differences between its Realtime and Pipelines products, both of which utilize Postgres logical replication. Realtime is designed for low-latency, best-effort message delivery to client browsers and apps over WebSockets, making it ideal for live UI updates, chat, and presence tracking. Conversely, Pipelines provides managed change-data-capture with at-least-once processing, persistent replication slots, and batching to reliably sync production data into analytical destinations. Choosing between them depends on whether the consumer is a human user needing instant updates or an external system requiring durable, guaranteed data movement.

Adding Async Streaming to Postgres Foreign Data Wrappers ↗

Traditional Postgres Foreign Data Wrappers suffer from high memory pressure and blocked execution because they rely on synchronous, pull-based batch fetching. Supabase solves this by introducing asynchronous streaming to their Rust-based Wrappers framework, decoupling remote network I/O from the Postgres execution engine. A background async task fetches remote rows incrementally and passes them to Postgres through a bounded, size-limited memory channel. This hybrid architecture drastically reduces memory usage during billion-row scans and accelerates the time-to-first-result for analytical queries against systems like ClickHouse.
