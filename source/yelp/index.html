As a result, production workloads achieved up to a 58 percent reduction in p99 latencies, significantly faster node restarts, and improved cluster stability.

S3 server access logs at scale ↗

Yelp engineered a scalable data pipeline to process and analyze terabytes of daily Amazon S3 server access logs across numerous AWS accounts. By compacting raw plaintext logs into compressed Parquet format via automated Amazon Athena queries and partitioning them efficiently, the system reduces storage size by 85 percent and object counts by 99.99 percent. This architecture powers object-level logging, cost attribution, and automated data retention policies by joining access logs with S3 inventory without relying on costly cloud trial data events.
