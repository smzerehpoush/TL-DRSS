How Discord Automates ScyllaDB Clusters at Scale ↗

Discord's persistence infrastructure team faced significant operational toil and risk when managing dozens of large-scale ScyllaDB clusters using fragile, uncoordinated scripts. To solve this, they built the Scylla Control Plane (SCP), a custom orchestration framework written in Rust with YAML-defined workflows and a SQLite-backed state machine. SCP provides built-in preconditions, idempotent tasks, tunable zonal parallelism, and automatic retries to safely handle complex operations like rolling restarts, OS upgrades, and node expansions. As a result, high-stakes infrastructure tasks that previously required grueling, all-day manual oversight are now fully automated and reliably executed in a fraction of the time.
