Estimating Incremental Lift in Customer Value (Delta CV) using Synthetic Control ↗

PayPal implemented a causal inference methodology called Delta CV to measure the incremental profit margin and revenue generated by customers after adopting new products or completing specific app actions. By utilizing a synthetic control group built via a K-nearest neighbors algorithm on 12 months of historical transactional features, the data science team matches product adopters with non-adopters to estimate long-term behavioral lift and ecosystem halo effects. This framework successfully evaluates over 40 products and actions, guiding strategic decision-making, marketing campaign ROI, and product placement across the platform despite challenges like chain adoptions and skewed metrics.

Leveraging Spark 3 and NVIDIA’s GPUs to Reduce Cloud Cost by up to 70% for Big Data Pipelines ↗

PayPal optimized its large-scale Apache Spark big data pipelines by migrating from CPU-based clusters to GPU-accelerated infrastructure using Spark 3 and the RAPIDS accelerator. By tuning Spark parameters like Adaptive Query Execution and partition sizes to make workloads more compute-bound, the team successfully reduced both runtime and resource requirements. This strategic migration and optimization process resulted in a significant cloud cost reduction of up to 70% for eligible data processing jobs. The project highlights the effectiveness of leveraging GPU parallelism for SQL-heavy big data operations beyond traditional machine learning use cases.
