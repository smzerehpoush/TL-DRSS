Why We Built a Write Back Cache for Our Asset Library with Google Cloud Spanner ↗

Squarespace improved the write performance of its Alexandria asset library service by implementing a write-back cache using Google Cloud Spanner. Previously, the system relied on synchronous writes to Google Cloud Storage, which suffered from object-level rate limits and unpredictable latency spikes. By offloading writes to Spanner and flushing them asynchronously to long-term storage, the team removed GCS from the critical request path and eliminated complex write-coalescing logic. This architectural shift resulted in a 70% reduction in average write latency and a 90% improvement in p99 latency.
