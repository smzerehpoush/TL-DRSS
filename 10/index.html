Smaller, faster, safer: running Kimi and GLM at scale ↗

Serving large long-context mixture-of-experts models like Kimi K-series and GLM 5.2 at scale on GPUs creates severe memory constraints due to KV cache growth and massive weight sizes. Cloudflare addresses this by layering FP8 KV cache quantization, INT4 weight compression, and KV cache integrity verification onto disaggregated prefill and decode GPU infrastructure. Quantizing the KV cache to FP8 doubles resident context memory capacity on H200 GPUs and increases peak decode throughput by 41% with no accuracy degradation. Compressing model weights to INT4 shrinks memory footprints by 40% and speeds up low-concurrency decode throughput by up to 55%, while lightweight page-tag checks protect shared cache memory from cross-request reads at under 1% overhead.
