Choosing QuePaxa, an unusual consensus algorithm ↗

Cloudflare built Meerkat, a globally distributed control plane key-value store powered by QuePaxa, an asynchronous, leader-optional consensus algorithm. Standard consensus protocols like Raft rely on strict leaders and fail-stop timeout detectors, which frequently cause cluster stalls and metastable election failures over volatile wide-area networks. QuePaxa solves this by allowing non-leader proposers to cooperatively converge on randomized proposal priorities and using client-side request hedging instead of timeout-based fault detectors. In global deployments spanning multiple continents, Meerkat achieves single-round-trip consensus for over 95% of decisions under normal conditions and gracefully degrades to roughly 65% throughput during leader crashes without ever halting the system.

How DeepL keeps closest-exit routing during maintenance with AWS Cloud WAN ↗

DeepL needed a zero-downtime strategy to drain traffic from individual AWS Direct Connect links during scheduled maintenance without disrupting local closest-exit egress routing for unaffected Regions. To accomplish this, the team utilized native Direct Connect gateway attachments in AWS Cloud WAN and applied BGP AS_PATH prepending on the target link. Because AWS Cloud WAN core network edges evaluate AS_PATH length before peer core routes, prepending five AS hops forces only the maintained Region's egress traffic onto peer edges while other Regions continue using their local exits. This technique eliminates route withdrawal convergence gaps and enables seamless link draining across a multi-Region hybrid environment.
