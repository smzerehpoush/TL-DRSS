Building a post-quantum certificate authority with Merkle Tree Certificates ↗

To prevent the performance degradation and scaling issues caused by large post-quantum cryptographic signatures in Web PKI, Cloudflare is launching a certificate authority that supports Merkle Tree Certificates (MTCs). MTCs batch certificates into an append-only Merkle tree, allowing clients to verify certificates using compact inclusion proofs against a signed tree head instead of validating individual, heavy signatures. This "issue by logging" architecture integrates certificate transparency directly into the issuance process rather than treating it as an add-on. A recent large-scale experiment with Google Chrome demonstrated that using landmark-relative MTCs, which distribute tree metadata out-of-band, resulted in a 9% faster median handshake compared to classical signature chains.
