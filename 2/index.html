How We Built TLX: A Hardware-Native GPU Compiler for Production ML at Scale ↗

Meta developed Triton Low-Level Extensions (TLX), an extension to the Triton programming model that addresses the gap between high-level productivity abstractions and low-level GPU hardware execution features. TLX introduces a Multiple Instructions, Multiple Warps (MIMW) abstraction that provides explicit warp-group orchestration, asynchronous memory movement, and cluster-level execution directly within Triton's Python-based environment. By exposing explicit execution control while maintaining automatic layout inference and autotuning, TLX simplifies kernel fusion and multi-stage pipelining across NVIDIA and AMD hardware. In production, TLX achieved a 20-25% end-to-end model FLOPs utilization for recommendation model training on NVIDIA Blackwell GPUs, reduced compute latency by up to two-thirds in recommendation inference, and powers distributed grouped GEMMs across large-scale LLM pretraining fleets.

How DeepL keeps closest-exit routing during maintenance with AWS Cloud WAN ↗

DeepL needed a zero-downtime strategy to drain traffic from individual AWS Direct Connect links during scheduled maintenance without disrupting local closest-exit egress routing for unaffected Regions. To accomplish this, the team utilized native Direct Connect gateway attachments in AWS Cloud WAN and applied BGP AS_PATH prepending on the target link. Because AWS Cloud WAN core network edges evaluate AS_PATH length before peer core routes, prepending five AS hops forces only the maintained Region's egress traffic onto peer edges while other Regions continue using their local exits. This technique eliminates route withdrawal convergence gaps and enables seamless link draining across a multi-Region hybrid environment.
