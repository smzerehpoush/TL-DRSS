Standard HTTP client-server exchanges reveal user IP addresses and TLS fingerprints to application backends, creating privacy risks for end users. Cloudflare announced the OHTTP Gateway, a managed service implementing the Oblivious HTTP standard that decapsulates encrypted requests at the edge before sending plain HTTP to application origins. Deployed across Cloudflare's global anycast network, the Gateway automates HPKE key management, reduces relay-to-origin latency, and integrates with Cloudflare Access for relay authentication. To enforce OHTTP's core separation-of-trust requirement, the Gateway automatically rejects traffic coming from Cloudflare-operated relays, preventing a single party from observing both client identities and payload content.
