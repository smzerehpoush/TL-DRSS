Cloudflare built Meerkat, a globally distributed control plane key-value store powered by QuePaxa, an asynchronous, leader-optional consensus algorithm. Standard consensus protocols like Raft rely on strict leaders and fail-stop timeout detectors, which frequently cause cluster stalls and metastable election failures over volatile wide-area networks.
