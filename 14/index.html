CASTLE: training natural language search before the first real query ↗

Airbnb faced a cold-start problem when introducing natural-language search because they lacked the historical user queries and relevance labels needed to train the model. To solve this, they developed CASTLE, a framework that jointly generates synthetic queries and correct relevance labels by using contrastive listing pairs derived from de-identified booking sessions. Human evaluations confirmed a 91% to 93% agreement rate on relevance assignments, effectively solving the cold-start challenge while continuously covering long-tail search intents.
