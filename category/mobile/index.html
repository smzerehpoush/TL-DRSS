Robinhood implemented a Server Driven UI (SDUI) platform to decouple interface updates from mobile app releases, significantly reducing the time required to modify customer-facing screens. By shifting UI logic to the backend and delivering view models instead of domain models, the team enables cross-platform consistency and reuse of design system components. To ensure safety and developer velocity, the system uses JSON schema generation for automated backwards compatibility checks and auto-generates client-side types for iOS, Android, and web. This approach has allowed over 80 engineers to scale UI development across 60+ screens, turning weeks-long release cycles into hours-long updates.

Building Obsidian, Tinder’s Design System ↗

Tinder developed Obsidian, a comprehensive design system, to address the inconsistency and maintenance challenges that arose as their application scaled over a decade. By utilizing design tokens as a single source of truth, the team synchronized styling across iOS, Android, and web platforms while simplifying the implementation of features like dark mode and accessibility improvements. The system leverages Figma, Tokens Studio, and Style Dictionary to automate the generation of platform-specific code artifacts. This infrastructure has successfully reduced design-to-engineering friction, accelerated development velocity, and ensured a more cohesive user experience.

A Better Way to Upload Images ↗

Squarespace addressed user friction in transferring photos from mobile devices to desktop website editors by implementing a seamless cross-platform handshake. The team rejected WebSockets due to complexity and overhead, opting instead for a polling-based architecture that utilizes standard REST APIs and a central job server to coordinate state between the web browser and the mobile app. This system triggers a push notification to the user's mobile device, which handles the image upload and notifies the desktop client once the asset is ready. The resulting integration provides a frictionless experience that significantly simplifies the content management workflow for users.

Instagram Data Saver Mode ↗

Instagram implemented a Data Saver Mode for Android to address high data consumption in markets with limited or expensive cellular connectivity. The engineering team introduced three primary levers: disabling video prefetching, disabling video autoplay, and allowing users to restrict high-resolution media to Wi-Fi only. By testing these configurations globally, the team identified an optimal balance that significantly reduced cellular data usage while maintaining acceptable app performance and engagement. The final feature, which defaults to disabling video prefetching and restricting high-resolution media to Wi-Fi, successfully improved the experience for data-conscious users.

Implementing Dark Mode in iOS 13 ↗

Instagram implemented system-wide dark mode support for iOS 13 by building thin, backwards-compatible wrappers around Apple's UIKit APIs. This approach allowed the team to maintain compatibility with older Xcode versions and iOS 12 while leveraging native dynamic colors and images. To facilitate testing without requiring iOS 13 beta builds, the team developed a 'fake dark mode' feature that forced the app to render dark styles on older OS versions. This strategy enabled broad internal testing and a consistent user experience across different iOS versions.
